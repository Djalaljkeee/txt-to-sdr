Справка по формату

Запись координат SDR33 — фиксированные колонки (всего 84 символа):

08CO               138600.959       -22005.533      0
││ ││              ││              ││              ││              │
1-2│ └─ 5–20 имя ──┘└ 21–36 X (N) ─┘└ 37–52 Y (E) ─┘└ 53–68 H ─────┘└ 69–84 код ┘
 └─ 3–4 подтип (CO — координаты)

Имя выравнивается вправо, числа — влево, поля дополняются пробелами. Строка 00NM… — заголовок файла, 10NM… — запись проекта; они повторяются в начале каждого блока точек.

TXT: имя,X,Y,Z, — по одной точке в строке, разделитель запятая, 4 знака после запятой.
