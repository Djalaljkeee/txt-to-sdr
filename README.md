# SDR ⇄ TXT конвертер

Одностраничный конвертер съёмочных координат между форматом **Sokkia SDR33**
(координатные записи `08`) и текстовым форматом `имя,X,Y,Z,`.

Открыть: `index.html` — обычный файл, работает локально, без интернета,
установки и зависимостей. Данные из браузера никуда не уходят.

## Возможности

* Перетаскивание нескольких файлов сразу; направление конвертации определяется
  автоматически по содержимому (расширение — только запасной вариант).
* Ручной режим: вставил текст слева — получил результат справа.
* Настройки:
  * число знаков после запятой отдельно для SDR и для TXT;
  * обрезка хвостовых нулей (`38644.000` → `38644`) — как в приборных файлах;
  * замена имён на сквозную нумерацию `1…N`;
  * деление на блоки по N точек с повтором заголовка;
  * свои строки заголовка (`00NM…`) и проекта (`10NM…`) — при загрузке `.sdr`
    они подхватываются из исходного файла;
  * разделитель TXT (`,` `;` таб, пробел) и запятая в конце строки;
  * перестановка X и Y, код точки, пропуск точек с нулевой высотой;
  * CRLF/LF и кодировка результата (Windows-1251 / UTF-8).
* Для каждого файла: число точек, диапазоны координат, предупреждения,
  первые строки результата и схема точек в плане.

## Формат SDR33, запись координат

Строка — 84 символа фиксированной ширины:

| Колонки | Поле                        | Выравнивание |
|---------|-----------------------------|--------------|
| 1–2     | тип записи `08`             | —            |
| 3–4     | подтип `CO` (координаты)    | —            |
| 5–20    | имя точки                   | вправо       |
| 21–36   | X (север)                   | влево        |
| 37–52   | Y (восток)                  | влево        |
| 53–68   | H (высота)                  | влево        |
| 69–84   | код точки                   | влево        |

```
08CO               138600.959       -22005.533      0
```

Строки `00NM…` (заголовок файла) и `10NM…` (проект) повторяются в начале
каждого блока точек. Записи других типов при чтении пропускаются и
подсчитываются в предупреждениях.

## Формат TXT

```
G4,38500.4060,-21981.2990,236.1090,
```

По одной точке в строке. При чтении конвертер терпимо относится к
разделителям (`,` `;` таб, пробелы), к строкам без высоты и к мусорным
строкам — они попадают в предупреждения, а не ломают разбор.

## Тесты

```
node test/run.js
```

Тесты извлекают ядро конвертации прямо из `index.html` (между маркерами
`==CORE-START==` / `==CORE-END==`), поэтому проверяется тот же код, который
выполняется в браузере. В том числе — что циклы SDR → TXT → SDR и
TXT → SDR → TXT возвращают исходный файл байт в байт.
